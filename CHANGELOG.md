# История изменений

## 1.0.2

- Добавлена ссылка на репозиторий внизу страницы.
- Файлы сборки получают уникальные имена, чтобы новая версия не подменялась устаревшим кэшем.

## 1.0.1

- Ввод ссылки в Web переведён на нативное браузерное поле: стандартные команды вставки и выделения работают без текстового соединения Flutter.
- Добавлена отдельная кремовая кнопка «Вставить» слева от «Скачать».
- Пустой буфер не стирает уже введённую ссылку.
- Сохранены автоматическое определение сервиса и отправка через Enter.

## 1.0.0

- Адаптивное приложение для YouTube и Twitter/X, выбор качества и скачивание через сторонние API.
- Фирменный дизайн, локальные шрифты, автоматическая публикация GitHub Pages.
