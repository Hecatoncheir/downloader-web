# Downloader — проверка API из браузера

Тестовое Flutter Web-приложение для Twitter/X и YouTube. Собственного сервера обработки нет: браузер обращается непосредственно к сторонним API.

## Запуск

```powershell
flutter pub get
flutter run -d chrome --web-port 18764
```

## Проверка

1. Вставьте ссылку или выберите пример.
2. Для YouTube выберите Cobalt. Для Twitter/X можно выбрать FxEmbed или Cobalt.
3. Нажмите «Получить ссылки». Это проверяет API, но ещё не файл.
4. Нажмите «Проверить загрузку»: приложение получает весь файл в память, показывает объём, затем предлагает сохранить его.
5. Если запрос файла заблокирован, попробуйте «Открыть напрямую». Браузер может открыть проигрыватель вместо скачивания; используйте его меню сохранения.
6. Проверьте воспроизведение и звук. Приложение автоматически их не проверяет.
7. При ошибке скопируйте журнал. В нём могут быть временные ссылки доступа; не публикуйте его без проверки. Для сетевых ошибок полезны вкладки Console и Network в инструментах разработчика браузера.

Ограничения: 40 секунд для API, 120 секунд и 200 МиБ для файла. Загрузка хранится в памяти вкладки; для теста выбирайте небольшие ролики. Кнопка отмены закрывает активный HTTP-клиент. Доступ к буферу обмена зависит от разрешений браузера.

## API

- `https://rue-cobalt.xenon.zone/` — начальный адрес Cobalt.
- `https://cobaltapi.cjs.nz/` — второй адрес для сравнения.
- `https://api.fxtwitter.com/` — FxEmbed, только Twitter/X.

Ни один адрес не считается гарантированно работающим. Доступность зависит от сети, ограничений платформ и владельцев экземпляров. CORS нельзя отключить настройкой Flutter. Наличие открытого API не гарантирует разрешение владельца на массовое использование: перед публичным запуском согласуйте условия. Ссылки, требующие авторизации, не поддерживаются. Объединение отдельных потоков и ответы Cobalt `local-processing` не поддерживаются.

## Сборка и GitHub Pages

```powershell
flutter build web --release --no-web-resources-cdn --base-href /downloader-web/
```

Для другого имени репозитория замените `/downloader-web/`. Для корневого домена используйте `/`.
Публикуйте содержимое `build/web`, не исходники. Для локального просмотра сборки:

```powershell
python -m http.server 18764 --bind 127.0.0.1 --directory build/web
```

Публикация: https://hecatoncheir.github.io/downloader-web/ . Репозиторий: https://github.com/Hecatoncheir/downloader-web . В `.github/workflows/pages.yml` настроена публикация через GitHub Actions при изменении `main` и при ручном запуске.

## Проверки кода

```powershell
flutter analyze
flutter test
flutter build web --release --no-web-resources-cdn
```

Успешная сборка не подтверждает скачивание с внешних сервисов. Интерфейс использует простой Cubit; обработка ответов API вынесена отдельно.
