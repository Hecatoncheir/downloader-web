## Что умеет

- **Определяет сервис по ссылке.** YouTube, Shorts и Twitter / X — без ручного переключения.
- **Показывает доступное качество.** Разрешение и примерный размер файла, когда источник отдаёт нужные данные.
- **Сохраняет на устройство.** С возможностью отменить загрузку или открыть файл напрямую.
- **Остаётся простым.** Адаптивная компоновка, мягкие анимации и локально подключённые шрифты.

## Как пользоваться

1. Вставьте ссылку в единственное поле через Ctrl+V, системное меню или кнопку «Вставить»: сервис определяется автоматически.
2. Нажмите «Скачать» — появятся доступные варианты качества.
3. Выберите вариант. «Скачать» получит видеофайл целиком, при обрыве попробует дозагрузку и передаст готовый MP4 в загрузки браузера. Во время получения можно отменить запрос.
4. «Открыть напрямую» — отдельное действие для просмотра исходной ссылки, а не замена скачиванию.
5. «Поделиться» загружает выбранный видеофайл в память вкладки. После подготовки появляется проигрыватель с предпросмотром. Нажмите «Сохранить / Поделиться», чтобы открыть системный диалог с самим файлом; на iOS выберите «Сохранить в Файлы», если этот пункт доступен. Предпросмотр использует уже загруженный файл без повторного обращения к источнику. При закрытии предпросмотра его временный адрес освобождается. Проверка сохранения на реальном iPhone пока не выполнена. Нужен браузер с поддержкой отправки файлов через Web Share; ссылка вместо файла не отправляется. Получение файла для отправки ограничено 200 МиБ и пятью минутами на попытку; ожидание ответа и пауза между порциями данных — 20 секундами. Если передача остановилась и известен полный размер, приложение дозагружает недостающие байты частями по 16 КиБ. При HTTP 429 оно ждёт разрешённого сервером срока; при истечении ссылки на Twitter-видео обновляет её и продолжает с прежней позиции. Если передача через туннель всё равно сорвалась, приложение пробует получить тот же выбранный файл напрямую. Источник должен разрешать получение файла из браузера; повторная попытка также может завершиться ошибкой.

Качество и разрешение берутся из реальных ответов API и имён файлов. Для YouTube проверяются 360p, 720p и 1080p; одинаковые результаты объединяются. Это не полный каталог всех форматов YouTube. Для Twitter показываются все доступные варианты MP4. Лучший вариант каждого видео скачивается через туннель Cobalt, остальные — напрямую с сервера видео прежним способом. Прямой запрос может быть отклонён источником (например, HTTP 403). Если известны длительность и битрейт, размер рассчитывается приблизительно и отмечается знаком ≈. Неизвестный размер не подменяется выдуманным.

Наличие ссылки не гарантирует доступность файла, звук или воспроизведение. Возможности зависят от сети, платформы и API. Защищённые видео, объединение потоков Cobalt `local-processing` и авторизация не поддерживаются. Кнопки «Скачать» и «Поделиться» сначала получают файл в память вкладки: действуют ограничения 200 МиБ и пять минут на попытку. В загрузки браузера передаётся уже полученный файл через локальный Blob URL. Приложение не может подтвердить, что браузер сохранил его на диск; сообщение о передаче браузеру не заменяет проверку списка загрузок.

Под формой показаны понятные сообщения об ошибках. Технические подробности скрыты. Для диагностики сети используйте Console и Network браузера.

## Интерфейс

- Тёплая тёмная палитра, кремовый текст, коралловый акцент.
- Nunito — заголовки и логотип; Nunito Sans — интерфейс; JetBrains Mono — небольшие служебные метки.
- Шрифты включены локально в `assets/fonts`, лицензии OFL расположены рядом.
- Логотип и пиктограммы: `assets/brand/*.svg`; отрисовка Flutter — `lib/brand.dart`.
- Иконки PWA и вкладки генерирует `python tool/generate_brand_icons.py` (нужен Pillow).
- Один столбец на телефоне, поле и кнопка в строку и сетка качества на широком экране. Плавное раскрытие результата учитывает системное отключение анимаций.
- Состояние: `LinkInputCubit` — ссылка и определение сервиса; `ProbeCubit` — запросы, форматы, отмена и загрузка. Форма не выбирает API вручную.

## API

YouTube: `https://rue-cobalt.xenon.zone/` (Cobalt).
Twitter/X: `https://api.fxtwitter.com/` (FxEmbed) для сведений о видео и прямого просмотра; Cobalt с `alwaysProxy: true` для подготовки скачивания через `/tunnel`.

Ссылка передаётся соответствующему внешнему сервису. Доступность не гарантируется. Открытость API не означает разрешения на массовую эксплуатацию; условия следует согласовывать с владельцем экземпляра.

## Разработка

```powershell
flutter pub get
flutter run -d chrome --web-port 18764
flutter analyze
flutter test
flutter build web --release --no-web-resources-cdn --base-href /downloader-web/
```

Для локального просмотра сборки используйте `--base-href /`, затем:

```powershell
python -m http.server 18765 --bind 127.0.0.1 --directory build/web
```

GitHub Actions проверяет код и публикует `build/web` при изменении `main` или ручном запуске. Версия Flutter закреплена в `.github/workflows/pages.yml`. Успешные тесты и сборка не подтверждают доступность сторонних видеосервисов.


## Автоматическая публикация версий

GitHub Actions запускает анализатор, тесты и Web-сборку:

- В pull request к `main` — только проверка, без публикации.
- При отправке изменений в `main` — проверка и обновление GitHub Pages.
- При отправке тега `v*` — проверка соответствия тега версии в `pubspec.yaml`, сборка и публикация этой версии.
- Вручную через Actions → «Проверка и публикация Flutter Web» → Run workflow.

Для выпуска следующей версии измените `version` в `pubspec.yaml`, например на `1.0.1+2`, затем выполните:

```powershell
git add pubspec.yaml
git commit -m "Выпустить версию 1.0.1"
git push origin main
git tag -a v1.0.1 -m "Версия 1.0.1"
git push origin v1.0.1
```

Тег должен совпадать с основной версией, без номера сборки после `+`. Несовпадение останавливает публикацию. Источник GitHub Pages — GitHub Actions. Точная версия, commit и ветка или тег опубликованной сборки доступны по адресу `https://hecatoncheir.github.io/downloader-web/deployment.json`.


Для проверки настоящего видео X отдельно от обычных тестов: `flutter test --dart-define=RUN_LIVE_VIDEO_TEST=true test/live_video_download_test.dart --timeout 360s`. Тест обращается к внешним сервисам и может занять несколько минут из-за ограничения частоты запросов. Проверенный файл публикации `2113136961292497205`: 1 919 669 байт, MP4 720×1280; SHA-256 `ea26a1bf7466b45852d679f3437c5635ecd03c25d4fb566119a85226cacec472`. Полное получение проверено через `ProbeCubit` на Windows; сохранение через меню iOS требует проверки на iPhone.

Браузерная проверка 22.10.2026: ссылка `2113136961292497205`, кнопка «Скачать», 720×1280, опубликованный интерфейс Chrome. Полное сохранение не подтверждено: туннель останавливается по тайм-ауту, прямой источник отвечает HTTP 403. Проверка через `ProbeCubit` на Windows не заменяет этот сценарий. Эксперименты с отдельными адресами частей и предварительным HEAD-запросом не устранили сбой и отменены.
